换网后要做什么

  1. 把浏览器书签里的旧 IP 换成新的局域网 IP，打开 http://<新IP>:8080/；本页所有链接会自动指向新 IP。
  2. 执行 bash ops/gitea-root-url.sh 更新 Gitea 的 ROOT_URL 并重启 Gitea，否则页面链接、克隆地址和 Actions 回调还是旧 IP。
  3. 手动把 .env 里的 NORA_PUBLIC_URL 改成新 IP，重跑 bash ops/apply-env.sh 并重启 NORA。
  4. 文档 docs/09-gitops/access-and-credentials.md 里的 192.168.1.102 按新 IP 替换。
  5. 不用改：10.10.10.10 相关的镜像名、Flux GitRepository 的 Service 域名、工作流里的 REGISTRY。
